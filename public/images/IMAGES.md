# Картинки

Положите сюда фото клиники. Имена файлов должны совпадать с путями в `clinic.config.ts`.

Кратко:

- `logo.svg` / `favicon.svg` - бренд
- `hero.*` - баннер на весь экран
- `about.*` - блок «О клинике»
- `team/doctor-*.*` - специалисты
- `services/*` - услуги

Сейчас лежат SVG-заглушки - сайт уже открывается без стоковых фото.
